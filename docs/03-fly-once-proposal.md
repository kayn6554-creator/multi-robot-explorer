# 课题草案：Fly Once, Localize All

现场无人机建模，为异构地面机器人提供共享坐标系。

> 标注【推演】的内容是设想，尚未验证。

## 核心问题

无人机飞一圈之后，狗、人形、移动机械臂这些高度不同、相机不同的机器人，能不能只靠相机在模型里定位到分米级？这个共享坐标系能不能替代联合 SLAM 和人工标定，直接支撑协作任务？

## 现状：三条路线，各缺一块

| 路线 | 代表工作 | 已做到 | 缺什么 |
| --- | --- | --- | --- |
| 卫星跨视角定位 | [FG²](https://openaccess.thecvf.com/content/CVPR2025/html/Xia_FG2_Fine-Grained_Cross-View_Localization_by_Fine-Grained_Feature_Matching_CVPR_2025_paper.html) (CVPR 2025)、[BEVLoc](https://arxiv.org/html/2410.06410v1)、[TransLocNet](https://arxiv.org/pdf/2512.10419v1)、[行星车定位](https://arxiv.org/abs/2601.09107v1) | 地面图对卫星或航拍正射图定位，FG² 在 VIGOR 上误差降 28% | 参考图过期、正射；米级精度（BEVLoc 轨迹误差约 28 m，TransLocNet 在 KITTI 上 6.47 m）；3 自由度 |
| 机器人点云配准 | [EPFL 2013](https://infoscience.epfl.ch/record/199733)、[灾害响应配准 2017](https://arxiv.org/html/1709.00587) | 空地点云对齐，2013 年达到 0.08 m | 依赖激光或深度；外观匹配失效；多为无人机在地面图里定位 |
| 三维基础模型 | [AerialMegaDepth](https://arxiv.org/html/2504.13157v1) (CVPR 2025)、VGGT、DUSt3R | DUSt3R 空地旋转准确率（5° 内）从 5.2% 微调到 56% | 只测位姿，没接机器人；地面图是人眼高度，航拍是 Google Earth 渲染 |

数据集 [CoPeD](https://arxiv.org/pdf/2405.14731)、[GA3T](https://researchdiscovery.drexel.edu/esploro/outputs/preprint/GA3T-A-Ground-Aerial-Terrain-Traversability-Dataset/991022179502404721) 有空地同步数据，但没有"无人机建图、地面机器人在图里定位"的基准。行业里机器狗各自用激光雷达加 RTK 建图，"多机协同"停在平台派单层面（[科技日报](https://www.stdaily.com/web/gdxw/2026-08/14/content_564217.html)、[新华网](https://www.news.cn/finance/20260821/4ebf76e750fe44b3a64c5cbc743879ea/c.html)）。

**交集空白**：用几分钟前现场拍的低空斜视模型，让贴地高度的机器人只靠相机，通过三维基础模型做到分米级 6 自由度定位，再把结果直接用于多机任务。

## 为什么是现在

1. **标定可以交给模型**：VGGT 一秒内从多张图输出相机位姿和点图。
2. **空地视角差能学**：AerialMegaDepth 用约 13 万张配对图把空地旋转准确率提高约 10 倍。
3. **建图变成分钟级**：高斯泼溅几分钟建出可渲染模型，已有人在里面做无人机定位（[ISPRS 2026](https://isprs-archives.copernicus.org/articles/XLIX-B2-2026/1183/2026/)）和导航（[Splat-Nav](https://arxiv.org/html/2403.02751v3)）。

## 新颖之处【推演】

| 角度 | 想法 |
| --- | --- |
| 视角 | 贴地视角是没人测过的区间。Go2 相机离地约 0.3–0.4 m，画面大半是地面，机器人高度本身就是新的评测维度 |
| 采集 | 为别人好定位而拍：以地面机器人的可定位性为目标规划航拍，多拍低角度立面 |
| 更新 | 同步点：某台机器人定位置信度下降时呼叫无人机补飞，"地图会过期"变成系统的一部分 |
| 记忆 | 地图是团队的活记忆：地面机器人把变化写回模型，无人机只重建变化部分 |
| 通信 | 用坐标说话，不传视频：共享坐标后，机器人之间只需交换三维锚点 |
| 换位 | 渲染队友看到什么：有了共享模型和队友位姿，可以回答"B 能不能看见那扇门" |

## 三个子问题

- **RQ1 贴地视角能定多准**：不同高度机器人在现场模型里的定位误差与成功率，对比卫星跨视角定位、联合 SLAM、激光雷达加 RTK。
- **RQ2 无人机怎么拍最有用**：以可定位性为目标规划拍摄与补飞，同等飞行时间下与标准航线比较。
- **RQ3 共享坐标系值多少**：指认交接、异构编队、观察者站位，比较任务成功率、准备时间、人工介入次数。

## 可能的推进路径

1. **零样本摸底**：拍一小块场地，把机器人视角的照片直接交给 VGGT，看能不能用 → 决定是否微调
2. **小型数据集**：几个场景，狗、人形、移动臂各走几条路线并记录真值 → 本身可以是贡献
3. **定位系统**：检索 + 细定位 + 时序融合，与现有路线对比 → RQ1 成文
4. **往外延伸**：按摸底结果选主动采集、活记忆更新或指认交接演示 → RQ2 / RQ3

零样本已经够好，就把重点移到 RQ2、RQ3；完全不行，"贴地视角为什么难"本身就是一篇分析。

## 风险与应对

| 风险 | 应对 |
| --- | --- |
| 零样本不行，数据又不够 | 先用 AerialMegaDepth 公开数据预训练；最坏写成评测与分析 |
| 狗的视角太低 | 加云台抬高，或先做人形和移动臂 |
| 光照和季节让模型过期 | 由"同步点"和"活记忆"解决，风险转为卖点 |
| 室内低空飞行安全 | 小机型加防护罩；或先用手持相机模拟航拍 |
| 已经有人在做 | 开工前用连接器再查新论文；贴地视角 + 闭环任务的组合仍有区分度 |
